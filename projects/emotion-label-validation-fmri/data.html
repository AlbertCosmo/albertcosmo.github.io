Data

Primary dataset (not ours)

Emo-FilM (Morgenroth et al., 2025): 14 short CC films, continuous emotion annotations, fMRI, physio.

  • Annotations: OpenNeuro ds004872 (CC0)
  • fMRI / physio: OpenNeuro ds004892 (CC0)

What this project keeps in git

  • Processed text signals and 50-item human series (JSON under data/transcripts/).
  • 1 Hz visual features for Payload & TearsOfSteel; audio features for TearsOfSteel.
  • Result tables and publication figures (not raw BOLD).
  • Analysis code and download scripts.

What is local-only (not redistributed here)

  • Preprocessed BOLD NIfTIs (~9 GB subset; full set ~131 GB) — obtain via OpenNeuro / script.
  • ROI decode caches (*.npz voxel matrices).
  • Experiment film cuts (*_exp.mp4) — not on OpenNeuro; restore from original media archive if available.

Film media

Tears of Steel is freely downloadable (Blender Open Movie, CC-BY). Script: scripts/download_films_cc.sh. Other titles need the Emo-FilM experiment cuts for exact duration alignment.
