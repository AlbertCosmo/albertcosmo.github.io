Reproduce

Jessica Thach Thao Le & Albert Le Thanh Nhan · code: AlbertCosmo/emotion-label-validation-fmri

Environment: Python 3.11–3.12, scientific stack below. Large BOLD stays local; scripts download what they need.

Setup + tables + figures

git clone https://github.com/AlbertCosmo/emotion-label-validation-fmri.git
cd emotion-label-validation-fmri
python -m venv .venv && source .venv/bin/activate
pip install numpy scipy pandas scikit-learn nibabel nilearn matplotlib

# Annotations + minimal BOLD subset (~9 GB)
bash scripts/download_openneuro_subset.sh

# Optional: CC Tears of Steel film
bash scripts/download_films_cc.sh

# 50-item series (if regenerating from OpenNeuro)
python src/analysis/extract_multi_item.py --all-items

# Aggregate publication tables
python src/analysis/run_all_stats.py
python src/figures/make_publication_figures.py

Brain decode (requires local BOLD under ~/ds004892)

# Occipital extract + decode (subjects pre-specified by FD)
python src/analysis/decode_brain.py extract Payload sub-S08 sub-S05 sub-S11 sub-S15 sub-S06
python src/analysis/decode_brain.py extract TearsOfSteel sub-S31 sub-S08 sub-S11 sub-S25 sub-S04
python src/analysis/decode_brain.py decode Payload
python src/analysis/decode_brain.py decode TearsOfSteel

# Affective ROIs
python src/analysis/extract_affective_rois.py
python src/analysis/decode_affective.py

# Multi-item brain
python src/analysis/decode_multi_item_brain.py --rois network --items all

# Physio agreement
python src/analysis/analyze_physio.py

What you should not need

  • Full 131 GB ds004892 tree for the analyses reported here (subset is enough).
  • Sci-Hub or other illegal article downloads — primary paper is open access.
  • The presentation site at jessicathao.github.io as a data source.

Handoff notes: repo docs/SESSION_NOTES.md, docs/WEBSITE_HANDOFF.md, docs/ANALYSIS_STATUS.md. NOTICE applies to reuse of this reanalysis code.
