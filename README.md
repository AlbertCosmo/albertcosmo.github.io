# Albert Le Thanh Nhan — Personal Website

This repository contains the source for my personal academic website.

## Deployment

This site is deployed via GitHub Pages at:

https://albertcosmo.github.io/albert/

## Structure

- `index.html` — Main website (single-file, Tailwind CDN)
- `assets/` — Images and static files

## How to update

1. Edit `index.html`
2. Commit and push to `main` branch
3. GitHub Pages will automatically redeploy
