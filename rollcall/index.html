Roll Call

First, add this to your Home Screen

  1. In Safari, tap Share (the square with an arrow).
  2. Tap Add to Home Screen, then Add.
  3. Open Roll Call from the new icon and import your rosters there.

The Home Screen app keeps its own storage, separate from Safari. Rosters imported in a Safari tab won't carry over, and Safari may clear site data after 7 days without a visit.

Import your rosters

Class rosters are not stored on this website. Import your roster file once on each device; it stays only on this device and the app then works offline.

From a file

Choose rollcall-rosters.json (for example from the Files app, iCloud Drive or AirDrop).
